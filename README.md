# تطبيق دردشة خاص (كمبيوتر)

هذا مشروع كامل يجهز لك تطبيق دردشة بسيط وخاص لشخصين فقط باستخدام:
- **سيرفر WebSocket** خفيف.
- **تطبيق سطح مكتب (Electron)** يعمل على ويندوز/ماك/لينكس.

> الفكرة: أنتم الاثنين فقط تتصلون على السيرفر باستخدام **كلمة سر مشتركة**، والسيرفر يسمح بحدّ أقصى شخصين فقط.

---

## المتطلبات

- تثبيت Node.js (إصدار 18 أو أحدث).
- اتصال بين جهازين (نفس الشبكة أو عبر الإنترنت مع فتح المنفذ).

---

## الخطوات بالتفصيل

### 1) تشغيل السيرفر

1. ادخل مجلد السيرفر:
   ```bash
   cd server
   ```
2. ثبّت الحزم:
   ```bash
   npm install
   ```
3. شغّل السيرفر مع كلمة سر مشتركة (أنت وحبيبتك نفس الكلمة):
   ```bash
   CHAT_SECRET="my_shared_secret" PORT=8080 npm start
   ```
   - استبدل `my_shared_secret` بكلمة قوية.
   - يمكنك تغيير المنفذ إذا تحب.

### 2) تشغيل تطبيق الدردشة (على كل جهاز)

1. ادخل مجلد العميل:
   ```bash
   cd client
   ```
2. ثبّت الحزم:
   ```bash
   npm install
   ```
3. شغّل التطبيق مع بيانات الاتصال:
   ```bash
   CHAT_SERVER_URL="ws://IP-OF-SERVER:8080" CHAT_TOKEN="my_shared_secret" CHAT_NAME="اسمك" npm start
   ```
   - `IP-OF-SERVER` هو IP الجهاز اللي يشغل السيرفر.
   - `CHAT_TOKEN` لازم يطابق `CHAT_SECRET`.
   - `CHAT_NAME` اسمك (مثلاً: Ali أو Noor).

> إذا كنتما على نفس الجهاز، استخدموا `ws://localhost:8080`.

---

## تحويل التطبيق إلى ملف exe (ويندوز)

> ملاحظة: بناء ملف exe يحتاج ويندوز أو بيئة تستطيع البناء لويندوز.

1. ادخل مجلد العميل:
   ```bash
   cd client
   ```
2. ثبّت الحزم:
   ```bash
   npm install
   ```
3. ثبّت أداة البناء:
   ```bash
   npm install --save-dev electron-builder
   ```
4. أضف سكربت البناء داخل `client/package.json`:
   ```json
   "scripts": {
     "start": "electron .",
     "build:win": "electron-builder --win --x64"
   }
   ```
5. شغّل البناء:
   ```bash
   npm run build:win
   ```

ستجد الملف داخل:
```
client/dist/
```

---

## كيف تخلي التطبيق آمن أكثر؟

- **استخدم VPN** أو شبكة خاصة.
- فعّل HTTPS/WSS (شهادة SSL) إذا كان السيرفر على الإنترنت.
- اجعل كلمة السر قوية وطويلة.

## ملاحظات

- السيرفر يسمح بحد أقصى **شخصين** فقط.
- لو دخل شخص ثالث بنفس كلمة السر، السيرفر يرفضه تلقائيًا.
- لو أردت تشفير الرسائل فعلاً، يمكن إضافة تشفير طرفي (E2E) لاحقاً.
